NEW TYPES
---------
PermissionResolutionRequest — record(Actor, PermissionKey, ResourceScope); validates all fields;
  of() factory. Encodes "who wants to do what on which scope."

PermissionResolutionSnapshot — record(Collection<RoleAssignment>, Map<RoleKey, Role>); both
  fields defensively copied (List.copyOf / Map.copyOf — rejects null elements at construction);
  of() factory. Carries the data the resolver needs without coupling to a persistence mechanism.

PermissionResolution — sealed interface (same style as AccessDecision) with inner Granted and
  Denied records. Each carries actor, permission, target (ResourceScope), and a non-blank reason.
  Factory methods: PermissionResolution.granted(...) / .denied(...). isGranted() on both subtypes.

Exception hierarchy:
  CustosSecurityException (base, extends RuntimeException)
  └─ CustosInvariantViolationException — hard invariant violated; callers must treat as fatal
     └─ CustosAgentSuperAdminInvariantViolationException — carries the offending Actor

INTERNAL STRATEGIES
-------------------
ResourceScopeHierarchy (package-private interface):
  parentOf(ResourceScope) → ResourceScope|null
  covers(assignmentScope, targetScope) → boolean

DefaultResourceScopeHierarchy (package-private final class):
  Implements the sealed-switch parent walk and coverage rules. Extracted from DefaultPermissionResolver.

PermissionImplicationRules (package-private interface):
  permits(Set<PermissionKey> rolePermissions, PermissionKey requested) → boolean

DefaultPermissionImplicationRules (package-private final class):
  Encodes: update→read, publish→read, no other implications. Extracted from DefaultPermissionResolver.

UPDATED DefaultPermissionResolver
----------------------------------
Public default constructor: new DefaultPermissionResolver() — wires DefaultResourceScopeHierarchy
  and DefaultPermissionImplicationRules internally.
Package-private constructor: accepts strategy interfaces for injection (used by strategy unit tests
  and future callers that want to swap rules without subclassing).

Evaluation order preserved:
  1. enforceAgentSuperAdminInvariant → throws CustosAgentSuperAdminInvariantViolationException
  2. hasCoveringSuperAdmin → returns PermissionResolution.Granted("SUPER_ADMIN bypass")
  3. resolveByScope → walks scope hierarchy; returns Granted with role+scope in reason, or Denied
