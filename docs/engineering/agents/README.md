# Engineering Agent Artifacts

This is the sole canonical location for durable agent work artifacts.

| Artifact | Location |
| --- | --- |
| Task specification | [tasks/](tasks/README.md) |
| Completion, discovery, or documentation report | [reports/](reports/README.md) |
| Independent review | [reviews/](reviews/README.md) |
| Open recovery state | [checkpoints/](checkpoints/README.md) |
| Reusable artifact templates | [templates/](templates/) |

The former `docs/agents/` location is only a compatibility marker. The `tasks/legacy/` subtree
preserves earlier task specifications without presenting them as active work.
