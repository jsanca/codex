# Security Documentation

Custos is Codex's transport-agnostic domain authorization kernel. Start with the
[Custos model](CUSTOS-MODEL.md), then consult the
[implementation checklist](CUSTOS-IMPLEMENTATION-CHECKLIST.md) and the canonical ADR corpus.

The historical future-forward Custos proposal is retained under
[../roadmap/future/](../../engineering/roadmap/future/custos-domain-authorization-model.md); the model and
checklist in this directory describe the current documented state.
